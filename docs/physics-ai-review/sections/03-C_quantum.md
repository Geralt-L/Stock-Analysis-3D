3. **本节所有复杂度/加速主张都只有 FLOPs 或迭代数，没有一条给出墙钟时间或解码延迟。** 这是本主题最系统性的缺口，见小结。

这两周最扎实的进展全部集中在"ML 服务量子硬件"这一侧，而且出现了一个**清晰的方法论收敛**：两篇互相独立的解码工作（一篇做表面码、一篇做级联码）不约而同地做了同一件事——把解码目标从"重建物理错误链"改成"直接判别逻辑错误类"，并把神经网络严格限制成消息传递管线里的一个小零件（学边权、或只学四条通道怎么聚合），而不是端到端吃综合征的大模型。两篇都拿一个单隐层 MLP 打赢了参数量大两三个数量级的对手。**但这两篇的对手是谁，决定了这个"赢"值多少钱**：一篇的对照是被取了最坏迭代数的 Relay-BP 和最弱档的 BP-OSD(OSD-0)，另一篇的对照只有两个硬判决启发式——见下文逐条。

与这两篇配成一条链的是第三篇：**从综合征数据直接学噪声模型**（[arXiv:2609.00169](https://arxiv.org/abs/2609.00169v1)）。前两篇公认的软肋恰恰是"必须按噪声模型、按工作点分别训练"，这篇正好补在那个缺口上。本节把这三篇当**一条链**读——解码精度（L-NBP）/ 解码复杂度（分层消息传递）/ 噪声模型来源（张量网络学噪声）——而不是三条互不相干的新闻。

#### 1. L-NBP：把表面码解码从物理层改到逻辑层，线性复杂度下越过 MWPM 与 BP-OSD

**[arXiv:2608.27682](https://arxiv.org/abs/2608.27682v1)** `[受控基准]` `[原文核查]`

（蔚山大学 / POSTECH / 本-古里安大学 / 庆尚国立大学；Eliya Nachmani 在作者列，即经典神经置信传播的开创者之一；2026-08-27。事实核查结论：MOSTLY_CONFIRMED）

**定位**：这是本主题两周里论证最完整的一篇解码工作，核心主张是"BP 在表面码上不够准"这个长期共识很大程度上是**目标函数选错了**，而不是消息传递本身的能力上限。

**方法要点**：置信传播（BP）本身是线性复杂度，最适合实时解码，但表面码 Tanner 图短环多、校验矩阵高度退化，普通 BP 精度不够；业界的补救（BP-OSD 的有序统计后处理、Relay-BP 的超多次迭代）都把线性复杂度优势吃掉了。作者利用的结构性事实是：表面码纠错**只需要恢复逻辑算符，不需要精确的物理错误链**。于是 L-NBP 由两段串联、端到端联合训练：(a) 一个带可学习权重的 NBP 模块，权重 {α, β, η} 逐迭代独立，展开 ℓ̄=60 次迭代；(b) 把后验 LLR 加权聚合成一个**保留置信度的"软综合征"**，喂进单隐层 MLP（h=256），输出 4 类逻辑算符 {Ī, X̄, Ȳ, Z̄}。梯度从四分类交叉熵一路回传到每个 BP 权重，因此 NBP 不再被训练成"好的物理层解码器"，而是被训练成"能吐出利于逻辑分类的特征"的提取器。另一个被低估的复杂度来源是矩阵尺寸：BP-OSD 跑在 720×12750 的 detector error model 矩阵上，L-NBP 跑在 720×1530 的扩展校验矩阵上。训练在单张 RTX A5000 上，d=9 code-capacity 约 8 小时。实际评估码距为 **d=5, 7, 9, 11, 13**（d=3 只是 Fig. 1 的示意晶格，从未参与实验；这是语料复述里的一处错误，已按核查更正）。

**关键数字（每个都带对照基线与口径）**：

- 阈值 **17.5%**，对照 QECCT 17.1%、BP-OSD 16.5%、MWPM 14.5%。**口径**：这是 **code-capacity 消偏振噪声**下的阈值，不是电路级阈值；阈值只定义为 LER 曲线交点，17.5% vs 17.1% 只差 0.4 个百分点且**没有拟合误差棒**；BP-OSD 基线取的是**最弱档 OSD-0**（60 次加权最小和 + 固定缩放 0.625），文献里的强基线 OSD-CS/OSD-E 全文未比；MWPM 在消偏振下本就因分开解 X/Z 天然吃亏。
- d=13 时 FLOPs **0.89 M**，对照 BP-OSD 1.95 M、AMBP 95 M、QECCT 604 M（同为 code-capacity 口径）。
- 电路级噪声 d=9 的**每轮**（per-round，d=9 有 R=9 轮，不是整次解码总量）FLOPs：BP-OSD 3 M + 后处理 366 M = 369 M，Relay-BP 953 M，L-NBP 566 K + 12 K = **0.58 M**，即 BP-OSD 的 0.2%、Relay-BP 的 0.06%。**口径警告**：Table 1 给 Relay-BP 记 **18,080 次迭代**（=80+300×60 的**上限**）、给 AMBP 记 51×150 次，而这两者都是早停级联，典型迭代数远低于上限。论文自己在 Related Work 里写明这是 "in the worst case"，转头把最坏情形数字写进表格和"仅为其 0.06% 复杂度"的金句里而不加标注。**这是全文最大的口径问题：所谓"数量级加速"是"L-NBP 的固定成本 vs 对手的最坏情形"，且全部以 FLOPs 计，没有任何墙钟时间或解码延迟数字。**
- 唯象噪声 d=9 为 BP-OSD 的 2.3%；code-capacity d=13 为 54.4% 降幅。
- 消融（d=11，p=0.05，单一工作点）：完整版逻辑错误率 3.8×10⁻⁴；硬综合征直接喂 MLP 2.3×10⁻²（约 1.8 个数量级差，不是 3 个）；残差硬综合征（梯度断掉）4.5×10⁻¹、软综合征但 NBP 先单独训成物理层解码器再冻结 3.5×10⁻¹（这两个才是 3 个数量级）。
- 评估口径：每点至少 10⁵ 次 Monte Carlo 且收满 1000 次逻辑失败——但论文原句只对 **Fig. 5/6** 作此保证，Table 2 的消融 LER 不在保证内。

**需要打折扣的地方**：

- **精度上其实输给了真正的 SOTA**。电路级下论文自承 L-NBP "only slightly worse than Relay-BP"，但摘要只挑"匹配 BP-OSD"来说，Relay-BP 不进摘要、也不进"最佳精度-复杂度权衡"图。
- **"可扩展"在电路级是论断不是实测**。电路级只有 d=9 一条曲线，没有阈值也没有 LER-vs-d 曲线，可扩展性靠 O(n) 阶数与 FLOPs 计数论证。
- **核心设计点没有被消融证明有收益**。Variant E（跳过软综合征、直接喂后验 LLR）LER 为 4.0×10⁻⁴，与基线 3.8×10⁻⁴ 实质相当；论文只能退而论证输入维度优势（m vs 3n）。也就是说"软综合征"这一卖点在**精度上**并未被自己的消融支持——真正被证明缺一不可的是"端到端联合训练"和"不做硬判决"。
- MWPM 被脚注排除出 FLOPs 比较（理由是组合匹配不便折算 FLOPs），恰好把工程上最现实的快速基线从"复杂度最低"的宣称里拿掉了。
- **适用面被回避**：输出只有 4 类逻辑算符、不产出物理纠正算符，因此天然只适用于 memory 实验（电路级还只做了 rotated_memory_z），无法直接接晶格手术 / Pauli frame 追踪。论文没有 Limitations 也没有 Future Work 节，对此只字未提。
- 训练样本固定在 p=0.15 / 0.03 / 0.007 三个单点采集，跨 p、跨 d、跨噪声模型失配的泛化性一个实验都没做；每个码距每种噪声模型都要重训。论文未报告模型参数量。

#### 2. 分层消息传递解码级联码：固定消息规则，只让网络学"怎么聚合"

**[arXiv:2608.28571](https://arxiv.org/abs/2608.28571v1)** `[受控基准]` `[原文核查]`

（香港科技大学物理系 + SpinQ；2026-08-28。事实核查结论：CONFIRMED，37 条声明零错误）

**定位**：与上一篇思路高度平行、但用在级联码上——级联码的码距随层数指数增长、天然支持容错 gadget，瓶颈一直在于解码器必须逐个码族手工设计。这篇给出了一个通用解码工具。

**方法要点**：不把级联码压平到物理层（那会把高层稳定子变成高权重校验并制造稠密短圈），而是**直接把层级结构当作解码图**。每个第 ℓ 层量子比特带 X/Y/Z 三个变量节点，三类奇偶约束：稳定子约束（不只取 m 个独立生成元，而是把稳定子群每个非零元都作为约束）、层级约束、Pauli 兼容约束；再为每个 block 加入 auxiliary logical-observable triples 以缩短消息路径。消息规则**固定、无学习参数**：传的是 [0,1]^r 的向量值软信念（r=8）而非标量边缘，从而保留 block 内关联；用周期函数 φ(x)=sin²(πx/2) 把 mod-2 奇偶变成可微算子。神经网络**只负责聚合**四条通道（cross-Pauli / upward / downward / stabilizer）：一个隐层 80 维的 update MLP 出候选特征，一个隐层 8 维的 gate MLP 出门控。迭代结构为 2 个 warm-up block + 4 个 recurrent block 重复 R=22 次，**T ≤ 90 固定迭代 ⇒ 最坏时延有界**；权重在 recurrent 期共享。读出直接给逻辑错误类，从根上避免与观测综合征不自洽的纠正。优化器用 Muon（二维权重，lr 1e-3）+ AdamW（其余，lr 1e-4），500 epoch × 每 epoch 16000 条在线采样综合征；电路级用 Knill 传态纠错（ECT）微调 20 epoch，并把固定随机初态换成可学习的初始 embedding。

**关键数字（每个都带对照基线与口径）**：

- 级联 [[15,7,3]] 量子 Hamming 码，**码容量**噪声：bit-flip 伪阈值从 **bidirectional 硬判决基线**的 ~4.4% 提到 ~6.8%（+2.4 个百分点），L=3、p=0.035 时 block failure rate 1.6×10⁻⁵ vs 基线 1.2×10⁻²；去极化伪阈值 ~6.5% → ~12.3%（+5.8 个百分点，作者称"接近翻倍"），p=0.07 时"至少低四个数量级"。去极化增益远大于 bit-flip 的原因是 cross-Pauli 通道耦合了 X/Z 综合征，而基线分开处理二者。
- many-hypercube [[6,4,2]] **电路级**、Knill ECT：L=4、p=0.005 时每轮逻辑 CNOT 失效率比 **level-by-level 最小距离解码器**低 17 倍；p=0.002 时只剩 3.6 倍。
- 非 CSS 的 [[8,3,3]]（码容量）：伪阈值从 **local 硬判决**的 ~5% 提到 ~12.5%。
- 参照的零码率 hashing bound：去极化 18.9%、bit-flip 11.0%（引用值，非本文测量）。

**需要打折扣的地方**：

- **"SOTA"要补上论文自己的分母：全部基线只有两个硬判决启发式**（bidirectional hard-decision、level-by-level MD / local hard-decision），**完全没有对最大似然/张量网络近最优解码器、也没有对最基本的 BP 或 BP+OSD 做对比**。所谓"超越 SOTA"只意味着"打赢了两个硬判决器"。而且作者自承 bit-flip 那两三个数量级的差距部分来自基线为控制最坏运行时而人为截断了搜索空间——即基线是被自己的工程折中拖累的。
- **p\* 是伪阈值（相邻层曲线交点），不是真阈值**。作者在脚注和结论里诚实承认 L=2/3 的交点"未必代表真正的渐近阈值"，但摘要里的 "nearly doubles" 没有这个限定；[[15,7,3]] 只做到 L=3（表 S6 的 Lv4 为 n/a），两条曲线定一个阈值。把伪阈值与 hashing bound 并置属于苹果比橘子。
- **最亮眼的数字都在码容量噪声下**（假设综合征测量完美、错误 i.i.d.）；唯一做电路级的 many-hypercube 又假设单比特 Hadamard 与闲置比特完全无噪——对一个需要大量 ancilla 工厂与后选择的 Knill ECT 方案，这个假设相当宽松。
- 摘要说 "toward low-overhead fault tolerance"，但**全文没有报告任何 overhead 数字**：level-4 全后选择的接受率被承认"very low"，接受率、丢弃块数、ancilla 工厂时空开销一个都没给。
- **"最坏时延有界"是核心卖点却没有任何实测**：没有 wall-clock、吞吐或与硬判决基线的运行时对比。"有界"是算法性质，不等于"更快"。
- **单点取值有挑选嫌疑**：去极化"低四个数量级"取在 p=0.07——这个点已在基线自身 6.5% 伪阈值之上、却在本方法 12.3% 之下，等于拿一个已经崩溃的解码器和一个还在阈值以下的解码器比。电路级"17 倍"同样是单点，且论文承认更低 p 下两者都会被 error floor 锁死（作者归因于 level-4 态制备电路并非严格容错，与解码器无关）。
- **电路级对比不是严格同口径**：基线是作者自己重跑的，用了比 Ref. [14] 原文更严格的后选择规则（C2′/C3′ 而非 C2/C3）、归一化方式也改了（按整块而非按块内逻辑比特），摘要里没带这些限定。

#### 4. 全集成 CV-QKD 100 km：正密钥出得来，但把功劳记在"贝叶斯机器学习"上是论文自己的外推

（上海交大光子学与通信全国重点实验室为主，含上海量子科学研究中心、合肥国家实验室；通讯 Tao Wang / 曾贵华；2026-08-29。事实核查结论：**CONFIRMED，69 条声明零错误**）

**方法要点**：把激光器、发射机、接收机三大核心功能同时上片（混合 III–V/Si₃N₄ 自注入锁定激光器 + SOI 发射/接收光子集成电路），跑高斯调制相干态、外差探测、反向协商，符号率 100 MBaud，并给出端到端可组合有限码长安全性。本文的"ML 成分"是 **unscented Rauch–Tung–Striebel（URTS）平滑器**——前向 UKF 加一次 RTS 后向递推，作用在"相位-频率"状态空间模型上；物理约束以**手工固定的协方差矩阵**注入：Q=diag(10⁻⁶ rad², 10⁸ rad²·s⁻²)、R=0.3·I₂，取值依据实测激光器线宽给出的相位扩散动力学。全文**没有训练集、没有拟合参数、没有报告任何训练数据规模**。物理上之所以可行，是因为集成激光器本征线宽被压到 10 Hz 与 30 Hz（相对自由运转 DFB 的 160 kHz 压缩 >5000 倍），使每符号相位扩散方差只有 2.51×10⁻⁶ rad²。

**关键数字（每个都带对照基线与口径）**：

**需要打折扣的地方**：

- **"Bayesian machine-learning algorithm" 是包装**。URTS 就是 RTS（1965）套在 UKF 上，协方差手工固定，全程没有任何"学习"。更要命的是平滑器使用未来观测（非因果），在线性高斯模型下 MSE 必然不高于因果滤波器——摘要说的 "consistently outperforming the conventional UKF" 近乎数学必然而非实验发现；非因果也意味着**不能实时运行**，论文未强调这一点。
- **摘要的"最高每符号密钥率"被自己的 Table 1 推翻**：同表文献 [20] 在 5 km 报 9.3×10⁻² bit/symbol，高于本文最好的 6.81×10⁻²（25.25 km）。只有正文里带 "at this distance（在该距离上）" 限定的版本才成立。且"每符号"这个度量本身偏袒慢系统——本文只跑 0.1 GBaud，比同表 [32] 的 40 GBaud 慢 400 倍；**按绝对速率算，本文 100 km 的 29.3 kbps 比 [32] 在 10 km 的约 1.2 Gbps 低四个数量级**。
- **"首次"必须补上论文自己叠的限定词**：Introduction 称 "the first full-link implementation of a fully integrated CV-QKD system"，而 Table 1 中判定 "Full" 的判据由作者自己写（片上激光源 + Tx + Rx 同时出现在一条端到端 LLO 链路演示中），全表 19 行只有自己一行拿到 ✓；100 km 本身并不新（同表 [23] 已在 100 km/16 dB 做过集成 CV-QKD，只是渐近、TLO、片外激光）。**真正的新意是"在这个距离上做到可组合有限码长 + 片上激光"，不是"第一次到 100 km"。**
- **"Fully integrated" 名不副实**：链路里仍有分立 EDFA（−1 → 13 dBm）、光纤光开关、偏振控制器、AWG 和台式示波器；所有后处理**离线**完成，32-bit 验证哈希只是说"部署时"会用。这是采集 + 离线蒸馏演示，不是实时 QKD 系统。
- 150 km 只有渐近结果且统计极薄（150 个块成功 130 个，N=1.5×10⁸）；125 km 的"+32.0%"用的是自造基线（把本该走多观测合并路由的帧直接判为失败、分母仍保留全部信道使用）。
- 安全模型依赖可信探测器（η_D=0.408、v_el=0.28 假定 Eve 不可利用）与**假定的** ≥80 dB 背向反射隔离度；100 km 的过噪声上界是 140 个分块估计的**经验最大值向上取整**，却直接被赋予 ε=2⁻³²，并非严格推导的置信上界；参数估计采用 "no-sacrifice"（n=N）约定。
- "7.2 小时零相位滑移"讲的是载频跟踪稳定性，不是连续密钥生成——数据实际是 20 ms 一段段采集后拼接的。
- 数据仅"可向通讯作者合理索取"，无公开数据集或代码，URTS/UKF 对比难以独立复现。

#### 5. 我认为被分诊低估的一篇："经典训练、量子部署"需要重新思考泛化

**[arXiv:2608.31117](https://arxiv.org/abs/2608.31117v1)** `[受控基准]` `[摘要级]`

### 四、小结

这两周本主题的重心明显偏向"ML 作为量子系统栈里的一个可验证零件"：解码器、噪声模型学习、器件标定、相位恢复——而且赢的都是**小模型加强结构先验**，不是端到端大网络。两篇解码工作独立收敛到同一个设计原则（把目标从物理错误链换成逻辑错误类、固定消息传递规则、只让网络学权重或聚合），这比任何单篇的阈值数字都更值得记住；把噪声模型学习（[arXiv:2609.00169](https://arxiv.org/abs/2609.00169v1)）接在它们上游，才构成完整的一条链。

反方向上，QML 本体正在经历一轮自我校正：闭式经典替代、明确的"不主张量子优势"声明、以及对主流训练损失（矩匹配）泛化可靠性的直接质疑，都在把这条线从"寻找优势"推向"先把基线做对"。同时必须带上跨章限定：本窗口"经典方法能否追平量子优势实验"这条线的主要进展在《电子结构与多体》章（[arXiv:2609.01719](https://arxiv.org/abs/2609.01719v1)），本节不重复计数，但没有它，"进展全在 ML 服务量子硬件一侧"这个判断会失真。

需要点名的是本主题的一个系统性问题：**几乎所有解码/优势类结论都缺墙钟时间与同口径基线**——L-NBP 和分层消息传递都把"低延迟/有界时延"当卖点，却都只报 FLOPs 或迭代数（前者的"0.2%/0.06%"还是拿自己的固定成本比对手的**最坏情形**），且基线要么取最弱档（OSD-0）、要么只有两个硬判决启发式、要么是作者自己用不同后选择规则重跑的。CV-QKD 那条的"ML 决定成败"同样是从**最大**降幅 32.47% 外推出来的，平均优势只有 11%。读这批文献时，先看基线怎么设的，再看数字。

顺带纠正一条会影响全篇的概括：有审稿意见指出全文某处把"中国机构本窗口的工作"概括为"终点停在计算自洽或在测试集上调参"。**这个概括对本节的两篇中国机构精读都不成立**：[arXiv:2608.29200](https://arxiv.org/abs/2608.29200v1)（上海交大）是 100.8 km 端到端硬件并给出 ε≈1.4×10⁻⁹ 的可组合正密钥，[arXiv:2608.28571](https://arxiv.org/abs/2608.28571v1)（港科大）是算法与仿真工作但其问题不是"计算自洽"。该概括应限定到具体的材料合成 agent 类工作，不能作为全称判断。

最后是没有发生的事，按本节自己的证据标准表述：**窗口内没有一条经原文核查的量子机器学习硬件优势主张**；40 篇摘要级分诊里有 4 条跑了真机（IBM Heron r2 上的 7 变量临床生成模型、IBM 真机单步 MNIST 生成、ibm_fez 上 8 比特核估计、真实鬼成像光学系统），但规模都在个位数变量/比特量级，经典对照要么是作者自选小基线、要么论文自己就声明不主张量子优势。也没有"预训练基础模型"进入量子纠错或量子控制。这个方向目前的实际交付物，仍然是运行在经典计算机上、服务于量子硬件的那部分。
