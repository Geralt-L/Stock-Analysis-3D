#### 一、量子侧的真实增量在"用经典 ML 修量子硬件"，而且这两周第一次凑齐了"精度—复杂度—噪声模型来源"三段链条；"量子做 ML"这一侧可核查的证据以自我否定为主——但这句话有两个必须写出来的反例

**L-NBP：把表面码解码目标从物理错误链改成四类逻辑算符（[arXiv:2608.27682](https://arxiv.org/abs/2608.27682v1)）** `[受控基准]` `[原文核查]`
60 次可学权重 BP 迭代 + 单隐层 h=256 的 MLP 端到端联合训练，在 720×1530 的扩展校验矩阵上跑（BP-OSD 跑的是 720×12750 的 detector error model，这是复杂度差距的主因）。**阈值 17.5%，口径是 code-capacity 消偏振噪声（不是电路级）**，对照 QECCT 17.1%、BP-OSD 16.5%、MWPM 14.5%；这里的 BP-OSD 用的是最弱档 OSD-0（60 次加权最小和、固定缩放因子 0.625），高阶 OSD-CS/OSD-E 全文未比，MWPM 在消偏振下因分开解 X/Z 天然吃亏。17.5% 与 17.1% 只差 0.4 个百分点，论文把阈值定义为 LER 曲线交点，没有报告拟合不确定度。复杂度侧 d=13 在 **code-capacity 口径**下 0.89 M FLOPs 对 QECCT 604 M（该口径没有"轮"的概念，不能写成"每轮"）；电路级 d=9 的**每轮** 0.58 M 对 BP-OSD 369 M（0.2%）、对 Relay-BP 953 M（0.06%）——但 **Relay-BP 的 18,080 次迭代是论文自己在 Related Work 里写明的"最坏情形"上限（80 + 300×60 的早停级联），拿对手最坏情形比自己的固定成本**；更关键的是论文正文自承电路级精度"only slightly worse than Relay-BP"，即真正的强对手在精度上赢了 L-NBP，而 Relay-BP 既不进摘要也不进那张"最佳精度-复杂度权衡"图。电路级只跑了 d=9 一个码距、没有阈值或 LER-vs-d 曲线，所以"可扩展"在最贴近实机的噪声模型下是 FLOPs 计数论断而非实测。另需注意：训练样本固定在 p=0.15/0.03/0.007 三个单点采集，每个码距、每种噪声模型各训一个网络；消融只在 d=11、p=0.05 单点做，其中 Variant E（跳过软综合征直接喂后验 LLR）LER 4.0×10⁻⁴ 与基线 3.8×10⁻⁴ 实质相当——"软综合征"这个核心设计点在精度上并没有被自己的消融证明有收益，收益只在分类器输入维度。

**分层消息传递解码级联码（[arXiv:2608.28571](https://arxiv.org/abs/2608.28571v1)）** `[受控基准]` `[原文核查]`
固定消息规则、只让两个单隐层 MLP 学四条通道怎么聚合。`[[15,7,3]]` 去极化 pseudo-threshold 从 6.5% 升到 12.3%（论文摘要写"nearly doubles"，限定词是：pseudo-threshold 是相邻层曲线交点、不是真阈值，且 `[[15,7,3]]` 只做到 L=3，两条曲线定一个阈值）。**对照基线只有两个硬判决启发式（bidirectional hard-decision、level-by-level MD），没有 BP、没有 BP-OSD、没有张量网络最大似然**，作者自己还承认其中一个基线是被自己的运行时折中截断了搜索空间。头条的"17 倍"是 many-hypercube L=4、p=0.005 **一个单点**，p 降到 0.002 只剩 3.6 倍，且两个解码器都开始触 error floor；那个"至少低四个数量级"取在 p=0.07——这个点已经在基线自身 6.5% 的 pseudo-threshold 之上、却在神经解码器 12.3% 之下，等于拿一个已经崩溃的解码器比一个还在阈值以下的。电路级对比里的基线是作者自己重跑的，后选择规则比原文更严、归一化口径也改了。摘要提"toward low-overhead fault tolerance"，全文没有报告任何 overhead 数字。

**补上前两篇真实缺口的是第三篇：噪声模型的标定（[arXiv:2609.00169](https://arxiv.org/abs/2609.00169v1)）** `[真机验证]` `[摘要级]`
上面两篇公认的软肋是同一个——**要按噪声模型、按工作点分别训练**，而噪声模型本身从哪来没人管。这篇把故障事件概率当变分参数，以译码器预测与逻辑观测的二元交叉熵为损失做梯度下降（张量网络译码器提供精确最大似然与解析梯度）。据摘要，在 Google Sycamore 的电路级数据上从无信息先验出发，学到的噪声模型其逻辑错误率**与 Google 自己独立标定的探测器错误模型相差 2% 以内**——这是本窗口量子解码线里少见的、对照物是第三方独立标定而非作者自选基线的数字；热启动更新可实时跟踪器件漂移而无需重新标定。必须打的折：**此条只经摘要级分诊、未核查原文**，摘要没给数据量、重复次数、误差棒，也没有与既有标定方法的耗时/样本量对照。把它与前两篇串成一条线（精度 / 复杂度 / 噪声模型来源），比把三篇当三条独立新闻更接近事实。

**自我否定的那一侧，两条都只到摘要级，措辞要相应收紧。** [ZZ 特征映射的闭式经典替代（arXiv:2608.29422）](https://arxiv.org/abs/2608.29422v1) `[受控基准]` `[摘要级]`：据摘要，ZZ 特征映射在小带宽下诱导 signless Laplacian 度规、等价于一个闭式经典各向异性核。**但这条要降温半档**：所谓"移除量子线路没有可测预测损失"只建立在一个近红外光谱数据集的 20 个实验单元上（18 个配对自举 95% 区间含零），且是小带宽下的主导阶结论；该文在语料里 significance 只有 3、未做深读，不能读成对量子核方法的一般性判决。[矩匹配训练的生成模型泛化更差（arXiv:2608.31117）](https://arxiv.org/abs/2608.31117v1) `[受控基准]` `[摘要级]`：据摘要，用 MMD²（只比较 Pauli-Z 关联）训练的模型在最多 30 比特的基数约束数据集与基因组单核苷酸变异数据上泛化普遍不如似然训练模型，对照基线是似然训练的同类模型，口径是直接采样基准——这是对"经典训练、量子部署"主流工作流的一次结构性否定，但同样未核原文。

**反例一：期刊侧同期给出了一个表达力分离的正面论证。** [QuanONet，量子神经算子（Nature Machine Intelligence，10.1038/s42256-026-01289-7）](https://www.nature.com/articles/s42256-026-01289-7) `[受控基准]` `[期刊扫描·未核查]`（正式归属 C 章"量子计算与量子机器学习"，同一工作，本节与 D 章只作交叉引用、不重复计数）。作者自报，未核查原文：把连续非线性算子的万有逼近定理推广到量子域，并证明其密度矩阵隐式构造的二次特征框架给出 O(p²) 表达力上界，绕开匹配经典模型的 O(p) 线性容量限；变频率版本 TF-QuanONet"明显优于量子基线，在严格参数匹配下与经典框架有竞争力"，p→256 时收敛到内禀误差下限而经典基线方差大。**限定词要写全**：这是表达力上界的分离论证，不是硬件上的量子优势；论文自己的措辞是"competitive with"经典框架，不是"优于"。有了这一条，"QML 本体本窗口全是自我降温"这句全称判断不成立，正确写法是"可核查的实证证据以自我降温为主，而理论侧出现了一个反向的表达力论证"。

**反例二：本窗口最重要的一次"经典模拟反击量子优势"被主题切分埋掉了。** [用含时变分蒙特卡洛模拟 D-Wave 量子优势实验（arXiv:2609.01719）](https://arxiv.org/abs/2609.01719v1) `[受控基准]` `[原文核查]`（主分类 quant-ph，语料里被归入 B「电子结构与多体」并占了 B 的一个名额；见 B 章，此处不重复计数）。它的正确读法不是"经典方法推翻了量子优势"：只覆盖有 MPS 真值的中小尺寸（最大 N=64 二维柱面 / N=54 三维 dimer），作者 §V 自承外推到原实验最大最难实例"仍然代价过高"，±1 双模实例整体留给未来；唯一的大尺度"成功"N=128 diamond 根本没有真值，只能靠 TDVP 残差背书，而作者自己在附录 E 给出该指标不可靠的反例；代价是 2123.02 GPU 小时对 QPU 的秒级。真正该被记住的是那组消融——并行回火把误差 0.4096→0.0331、blurred sampling 0.2434→0.0338（对照是同一 ansatz 换采样器/估计量），即**采样器和估计量的选择比 ansatz 更决定成败**。

#### 二、最值钱的一类工作是给学习系统的物理接口划死上界，而不是刷指标；这类结果本窗口有四条，但只有一条经过原文核查

**互易性可以砍掉力学网络一半的学习能力（[arXiv:2609.04169](https://arxiv.org/abs/2609.04169v1)）** `[受控基准]` `[摘要级]`
据摘要（S4/N4，语料里只是 otherPapers、无深读）：Maxwell–Betti 互易使 p 个同时驱动与读出的自由度所对应的响应块落在余维 p(p−1)/2 的子空间，完全重叠时近一半目标空间不可达；**训练误差下界等于目标在共享自由度上反对称部分的范数，训练前即可算出**。这类结果的"对照基线"就是它自己的解析下界，不需要外部对照组——但也正因如此，它目前没有任何独立复现，全部证据是作者自己的数值：144 次二阶优化中 143 次逼近该下界 1% 以内，键局域对比学习 24 次中 22 次在 0.1% 以内；此外一份已发表的机器人超材料数据被证明在线性模型下无解。实践含义必须一并写出：**非互易耦合能恢复丢失的方向，但需要外部力矩源，网络必须变成主动系统**——这是一条对整个 physical learning 路线的结构性 no-go，类比互易性对光子器件的约束，比本窗口任何一篇"我们又训出一个网络"都更该被记住。

同族还有三条，成色依次递减：[RMI-ONN（arXiv:2609.02698）](https://arxiv.org/abs/2609.02698v1) `[真机验证]` `[摘要级]`——据摘要，级联线性自由空间光网络受 y=|Tx|² 的秩一判决矩阵所限，作者用无序介质做高维投影加可编程非负强度掩模与分区功率求和构成全光两层网络，并在同一光路下实测幅度/相位/偏振多模态的 MNIST、Fashion-MNIST 与 Quick Draw 分类；**摘要没有给出准确率数字，也没有给出与任何数字网络或单层光网络的对照，因此"突破秩一上限"目前只是存在性演示**。[保真度接口的精确连续盲方向（arXiv:2609.01797）](https://arxiv.org/abs/2609.01797v1) `[受控基准]` `[摘要级]`——据摘要，仅依赖两态保真度的量子表示学习接口在某些态族中存在精确的连续盲方向，作者构造的批算符二阶矩保留四态干涉信息，在"四光子含制备漂移基准"上把分布外相位误差降低 86%；对照是仅用两态保真度的同类接口，属作者自设的对照臂，摘要未说明该基准是实测还是仿真，本节按最保守计为受控基准。[高维投影追踪的算法阈值（arXiv:2608.29416）](https://arxiv.org/abs/2608.29416v1) `[纯理论]` `[原文核查]`——295 页、无一图一表；用"每步能从无序中榨多少信息"的预算约束刻画 Lipschitz 算法可达的投影分布。必须叠的限定词有四层：**只覆盖与维数无关的 Lipschitz 算法（含 Langevin 与 AMP，但不等于多项式时间算法，绝不是 P vs NP 意义上的硬度）**；可达性用 W₂ 而硬度只到 W_q（q<2），论文自己在 §7 给出 W₂ confinement 的显式反例，所以两半定理并非同一度量下的严格互补；号称的 O(N²) 复杂度前提是"已能 query 与 N 无关的 Lipschitz 马尔可夫控制函数"，也就是假设那个真正决定阈值数值的控制问题已经解出；而数值阈值被推给一篇在参考文献里标注 "In Preparation, 2026" 的姊妹篇——**你拿不到一个数**。论文里那句 "This is the first AMP algorithm with this property" 是口径极窄的 first（指用整族布朗桥揭示矩阵 G(t) 而非单个 G）；相对独立工作 Montanari–Zhou（[arXiv:2406.02970](https://arxiv.org/abs/2406.02970v1)）的真实增量主要在硬度侧与 Ising 侧，球面可达性并非首次刻画。

#### 三、光计算不冷，但它的计算基准全是玩具、领先指标多为自定义；而光学 AI 里本窗口真正上正刊的不是"算力"，是逆设计

**光子时域处理器（[arXiv:2608.29469](https://arxiv.org/abs/2608.29469v1)）** `[真机验证]` `[原文核查]`
TFLN IQ 调制器 + 色散光纤 + 反馈环，把计算维度从空间搬到时间：神经元是波形上的采样点、层是环路往返、连接是色散传递函数，全部计算走 1 个光口 + 4 路电 I/O + 2 个有源器件，MVM 做到 35×35、MMM 11×11。**实测的通用元素 MMM 吞吐是 3.036 TOPS（还是靠四波长并行凑的）；表 1 里的 500 TOPS / 266.1 TOPS/W 是外推/聚合值，推导在未随 v1 发布的 Methods 里，公开文件无法核验，而摘要和引言直接用 500 TOPS 代表本工作。** 更要紧的是口径提醒：在它自己画的表 1 里，Science 2024（Taichi）5.04×10⁴ TOPS、Science 2025 3.57×10⁴ TOPS、Nature 2023 7.48×10⁴ TOPS/W 都高出两到三个量级，**所以 3.036 TOPS 不能与 Taichi 一类算力数字并列比较**；唯一"大幅领先"的是作者自己新定义的"电学 I/O 效率"（吞吐 ÷ 电 I/O 通道数）——一个按其单光口 + 4 路电 I/O 架构必然赢的指标，且对照表在未发布的 Supplementary 里。任务侧同样要打折：分类只有 Scikit-learn Digits（8×8 降采样、1797 样本，95.3%，且并非原位训练所得）与二维 Two Circles 原位训练（92%，同规模数字 MLP 基本能到 100%）；500×500 蝴蝶重建 PSNR 15.09 dB、SSIM 0.67；随机天体图 FID 122、IS 2.527±0.121。精度约 4 bit、无光学非线性激活（回路里的"多层"在光域基本是线性运算级联）、依赖长色散光纤；摘要那句"生成通路上不出现任何数字采样与电学调制"只对 ASE 噪声驱动 MNIST 一个演示成立。每类演示都是单例，无重复性统计、无误差棒。

**同窗口 J 主题唯一的 Nature Materials 正刊走的是另一条路：逆设计。** [深度学习设计扭转 α-MoO₃ 多层中的纳米尺度极化激元传播（10.1038/s41563-026-02723-2）](https://www.nature.com/articles/s41563-026-02723-2) `[受控基准]` `[期刊扫描·未核查]`。作者自报，未核查原文：在 600–800 cm⁻¹ 此前未探索的频段实现 canalization/bicanalization/tricanalization，并在一片已有的 α-MoO₃ 双层上通过加一层达成目标传播，网络还外推到其他材料、预测可见到太赫兹的 canalization。摘要没有给出任何对照基线、误差口径，也没有说明演示是数值还是实测，本节按最保守计为受控基准。**它的意义是：把"光学 AI＝物理计算硬件"这个叙事框架本身当成了一次遗漏——本窗口光学侧证据强度最高的一条并不在算力赛道上。**

**去重声明。** Science 的量子光学自旋玻璃联想记忆（[10.1126/science.aec3917](https://www.science.org/doi/10.1126/science.aec3917)）与 Nature Communications 的里德堡多体时序学习（[10.1038/s41467-026-77083-1](https://www.nature.com/articles/s41467-026-77083-1)）**只归"光学光子学/凝聚态"一章计数，本节与"用物理方法理解机器学习"一章只做交叉引用、不重复计数**。顺带把前者的口径写清楚：那个"容量比 Hebbian Hopfield 界高最多七倍"是在 **16 个自旋**的网络上、且是"最多"档，这是漂亮的非平衡量子光学演示，不是存储技术的量级进展；该文的 identifier 还注明预印本为 [arXiv:2509.12202](https://arxiv.org/abs/2509.12202v1)，属"期刊见刊"而非窗口内新工作。

#### 四、神经采样器扎堆，唯一能当尺子的工具却没量过任何一把

**Kac–Ward 精确自回归采样（[arXiv:2608.24382](https://arxiv.org/abs/2608.24382v1)）** `[受控基准]` `[原文核查]`
把冻结自旋诱导的边界外场改写成与一个辅助自旋的两体耦合以保住平面性，再用矩阵行列式引理把每步塌缩成 r×r 行列式，每样本 O(N^{5/2})，有 pykacward 开源实现。它同时给出三样别人给不了的东西：严格 i.i.d. 构型、每个构型的精确归一化似然、每一步的精确条件概率。要打的折有四层：**它宣称的"为神经自回归采样器提供精确基准"全文一次都没兑现——没有对任何 VAN、张量网络采样器或并行回火做过基准比较，没有 KL、没有自由能差、没有一张对照表**；唯一的实证对照是 vanilla Metropolis，而 Γ(t)=δ_{t,0} 不是测量结果、是 i.i.d. 采样的定义性同义反复，把它画成"效率演示"实质是稻草人对照；对同类精确算法它是退步而非进步——比 2009 年 Thomas–Middleton 的 O(N^{3/2}) **慢一个 N 因子**，也就是说"平面、零外场"这一类的精确采样十七年前就解决了，本文真正的新意只是"逐自旋条件概率"；最后，挫折系统低温下 A=I−BD⁻ 指数病态、必须用任意精度算术，而这部分比特复杂度既不在 O(N^{5/2}) 里，也不在图 S1(a) 的墙钟曲线里（那条曲线只跑了非挫折的方格铁磁模型）。实测规模最大 L=32（1024 自旋），L=64 的比热曲线是对 ln Z 解析求导、不来自采样。

**同窗口至少有四类神经采样器等着被这把尺子量，一把都没被量。** [RGFM（arXiv:2608.23696）](https://arxiv.org/abs/2608.23696v1) `[受控基准]` `[原文核查]`——用 Polchinski 精确 RG 流当流匹配的概率路径，并证明速度场局域性长度正比于跑动尺度 Λ(t)⁻¹。折扣同样厚：**正文与表格里一个 FID 数值都没有（只以图 9(b) 的曲线出现），读者无从判断"substantially lower"是 20 vs 40 还是 60 vs 90**；唯一基线是被同一感受野约束绑住手脚的局域 FM，没有与任何全局模型、latent diffusion 或已发表的 FFHQ-64 数字比过；64×64 上"同为 10⁶ 步"掩盖了 batch 差异（RGFM 约 2.37×10⁸ 个 patch 梯度对基线 1.28×10⁸，1.85 倍；一维更悬殊，约 2.4×10⁸ 对 5×10⁷，4.8 倍），没有等算力对照来排除"单纯训得更多"；那句"全局 self-attention 要 >10 GB/图所以不可行"是作者自己选择在 U-Net 第一级分辨率放全局注意力的后果，实践中没人这么干；256×256 只用了 FFHQ 前 5,000 张、完全没有定量指标，作者自陈空间分离的面部部件不一致。另外三类只到摘要级：[小波条件 RG 多尺度采样（arXiv:2608.31114）](https://arxiv.org/abs/2608.31114v1) `[受控基准]` `[摘要级]`，据摘要在类 Ising 临界点每尺度仅需 O(1) 次扫描即去关联、总采样复杂度 O(log₂ L)（即尺度数 log₂ L × 每尺度 O(1) 次扫描，与"光学光子学/凝聚态"章 §2.4 的写法一致），但**它的"对照"是"簇算法在弱阻挫下即失效"这一已知事实，而非同台跑分**；[SSEP/ASEP 的变分自回归网络（arXiv:2608.25606）](https://arxiv.org/abs/2608.25606v1) `[受控基准]` `[摘要级]`，先复现一维有限时与二维张量网络长时结果作为验证，再推进到三维有限时，"三维首次给出活跃-非活跃相变的有限时标度关系"是作者自报、未核查原文；[FrOGS 合金采样器（arXiv:2609.02948）](https://arxiv.org/abs/2609.02948v1) `[受控基准]` `[摘要级]`，据摘要在统一绝对自由能标度下重建 AgPd 与 CuAu 相图，唯一对照是一个自回归基线 SEGAL（后者在 CuAu₃ 相上失败）——**注意该条同时出现在 arXiv 语料与非 arXiv 扫描 #95，计一项工作**。

#### 五、真正的冷角：被浪潮"绕过"的不是没被碰，是碰完之后问题结构没变——但这个概括的适用范围要写死

**另一个冷角是"用 ML 仲裁凝聚态争议"，本窗口只有一例，而且不成立。** [用平坦磁能景观解决 RuO₂ 磁基态争议（arXiv:2609.03274）](https://arxiv.org/abs/2609.03274v1) `[受控基准]` `[原文核查]`（详见 J 章，此处只作方法论引用）：标题里的"Resolving"名不副实——论文并未判定基态是什么，而是宣称问题本身不成立，没有新实验、也没有可证伪的预言。**最致命的是拟合误差大于要分辨的效应**：广义自旋-晶格哈密顿量的 MAE 是 14 meV/atom（215 个磁构型），而全文物理就是几个磁构型"近乎简并"、RuO₂ 相关磁能差通常在 meV/atom 甚至更小；"35 eV 能量跨度"这个分母把误差包装成约 0.04%，但那个跨度来自把局域磁矩扫到极端值产生的巨大非磁性能量变化，与近简并问题无关，论文没有给任何误差棒或交叉验证。所谓"与实验定量吻合"是把五组自由可调的空位浓度 (c_Ru, c_O) 事后分配给五篇已发表实验，零留出预言；而模型给出的富缺陷样品 Mstag@300 K ≈ 1.5 μB/Ru 比文献里任何声称的交错磁矩（~0.05 μB 量级）高出 1–2 个数量级，论文从未正面处理。数据与代码不公开。

**最后是一条我原来写反了的判断，必须改写。** 上一稿把 [全集成 CV-QKD（arXiv:2608.29200）](https://arxiv.org/abs/2608.29200v1) `[真机验证]` `[原文核查]` 说成"物理先验定量决定成败的案例被低估"——这句话对"ML 成色"那一半打了折（所谓"贝叶斯机器学习"就是 UKF 套一条 RTS 后向平滑，Q=diag(10⁻⁶,10⁸)、R=0.3I 手工固定，全程无训练数据、无学得参数；平滑器使用未来观测，在线性高斯模型下 MSE 必然不高于因果滤波器，所以"consistently outperforming UKF"接近数学必然而非实验发现，也因此不能实时），却对"决定成败"那一半全盘接受了论文最强的框架。**改写后的正确口径**：URTS 相对 UKF 的**平均**优势只有 11%（2000 帧掩蔽导频的 MSE 比 1.1097，95% CI 1.1018–1.1191，对应 ξ̄=1.196×10⁻² vs 1.078×10⁻² SNU）；"UKF 拿不到正密钥"这个结论用的是**观测到的最大**降幅 32.47% 反推出的过噪声上界 2.443×10⁻² SNU，若用均值而非极值该结论未必成立；而且论文从未把 UKF 跑完整条密钥提取链，全部是掩蔽导频 MSE 实验加噪声模型外推，"每第五个导频掩蔽"本身也是人为构造的理想基准。该文的其余"首次"同样要补限定词：Introduction 的"首个全集成 CV-QKD 全链路实现"判据是作者自己写的，全表 19 行只有自己拿 ✓，而 100 km 距离本身早有人做过（同表 [23]，渐近、TLO、片外激光）；摘要的"集成 CV-QKD 最高每符号密钥率"被自己的 Table 1 推翻（[20] 在 5 km 报 9.3×10⁻² bit/symbol，高于本文最好的 6.81×10⁻²），只有带"在该距离上"限定的版本成立；"fully integrated"的链路里仍有 EDFA、光纤光开关、偏振控制器、AWG 与台式示波器，所有后处理都是离线的。**它剩下的、仍然成立的价值是**：这是本窗口唯一一个把估计器选择与一条可组合安全余量直接挂钩的案例（100.8 km、ε≈1.4×10⁻⁹ 的可组合正密钥是真硬件结果），但"定量决定成败"只在作者的最坏情况外推口径下成立。

**证据层级不能被抹平。** 本节挂了标签的 36 项工作里，**11 条**来自经全文事实核查的 deepReads（其中 3 条是 B/K 章的交叉引用），**15 条**只经过摘要级分诊，**10 条**只来自期刊/公司扫描（只确认了存在性与日期，说法为原样转述）；另有 aec3917 与里德堡两条按下述纪律只作交叉引用、不挂标签也不计数。四个主题合计只有 **8 篇** 精读经原文核查（C 3、J 3、L 2、M 0），其余 129 条只到摘要级；**医学物理一篇精读也没有**；这四个主题的 triage significance 最高只到 4，没有一条 5。相应的口径纪律是：摘要级条目一律写"据摘要"，期刊/公司扫描条目一律写"作者自报，未核查原文"，新闻稿与公司博客不当既成事实用。语料说明里"otherPapers 引用时措辞要相应保守"这一条，在本期 C 章被违反得最明显——一条未核查的 S3 条目（2608.29422）顶掉了已核查的 S4 精读（2608.29200）占了重点名额，本节已按上文口径把两者都补回并各自标层级。

**两条我不同意的意见，以及理由。** 一、[reader-14] 建议把 M 主题的重点名额让给其他章未入选的高分深读。我不改：**M 是"剩余桶"，它的低分本身就是本节要报告的事实**——一个方向本窗口没有出现方向性突破，也是一条结果；把名额挪走等于把这个信号抹掉。我的处理是保留 M 的位置，但把它从"重点工作"降级为"冷角"叙述，并把 22 篇、0 精读、最高 significance=3 这三个上限明写出来。二、[hype-3] 建议在证据层级不同的两侧之间"不比强弱"，我部分采纳但不完全同意：证据层级必须标注（本节已逐条标），但当一侧是 PR 通稿、另一侧是带 SI 且被逐条核查的 32 页论文时，**说"无法比较"本身就是给 PR 一侧免费的抬举**；正确写法是标注层级之后仍然给出方向性判断，并说明该判断依赖哪一层证据。

**最后一条要纠正的、来自邻章的判断。** [industry-labs] 写"中国机构本窗口的三份工作共享同一弱点：终点停在计算自洽或在测试集上调参"。**仅按本节这四个主题的 affiliations 就能证伪**：上海交大的 CV-QKD（2608.29200）是 100.8 km 端到端硬件并给出 ε≈1.4×10⁻⁹ 的可组合正密钥；上海交大 + Aalto 等的光子时域处理器（2608.29469）是实测硬件；北邮 + 中科院理论物理所等的 Kac–Ward（2608.24382）是解析精确算法；另有港科大的级联码解码（2608.28571）与大连理工的 RuO₂（2609.03274）。该判断应限定到"材料合成 agent 类的那三份工作"，不能作为全称判断使用。

**一个小而典型的口径样本，供全篇引用时套用。** [QArray+（arXiv:2609.02736）](https://arxiv.org/abs/2609.02736v1) `[受控基准]` `[摘要级]` 的标题里写着 "GPU-accelerated"，但据摘要它只给了绝对耗时（JAX/GPU 下 64 个量子点的 100×100 栅压电荷稳定图约 0.17 秒），**没有给出相对 QArray 原版或 CPU 实现的加速比**。这类"标题宣称加速、正文只给绝对数"的写法在本期语料里不是孤例，引用时应当直接写成"未给出加速比"，而不是替作者补一个想象中的倍数。
