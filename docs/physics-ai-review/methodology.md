# 附录 B：方法与覆盖范围

这份综述不是"搜几个关键词然后让模型写摘要"。下面把每一步的口径、样本量和已知盲区都写出来，便于复核与复现。

## 1. 检索：arXiv 侧

- **窗口**：2026-08-23 00:00 — 2026-09-06 23:59（`submittedDate`，即 v1 提交时间）。
- **覆盖**：通过 arXiv API 全量抓取窗口内以下类别的全部论文（不做关键词预过滤）：
  `physics.*`（22 个子类）、`cond-mat.*`（9 个）、`astro-ph.*`（6 个）、`hep-ph / hep-ex / hep-th / hep-lat`、`gr-qc`、`nucl-th / nucl-ex`、`quant-ph`。
  各类别返回量：physics 954、cond-mat 1096、astro-ph 875、hep+nucl+gr-qc 907、quant-ph 668。
- **AI 侧补充**：`cs.LG / cs.AI / cs.NE / cs.CE / stat.ML / math.NA / cs.CV / cs.CL / cs.MS / math.DS` 用 36 个物理关键词做定向抓取（`abs:` 字段），得 867 条。
- **去重后**：窗口内唯一物理类论文约 **4,425 篇**。
- **覆盖完整性**：arXiv 全文检索索引在成稿时截止于 2026-09-03T17:59Z，恰好对应最新公告日 **2026-09-04**（成稿日 09-06 为周日，arXiv 周末不公告）。因此窗口内**所有已公开**的预印本都在检索范围内，不存在尾部缺口；09-03 14:00 ET 之后提交、尚未公告的论文对任何人都还不可见。

## 2. 筛选：关键词 → 分诊 → 漏检回捞

1. **关键词初筛**：约 130 条强信号正则（machine learning / neural / MLIP / deep potential / neural operator / PINN / diffusion model / LLM / equivariant / simulation-based inference …）加一组弱信号（需命中 ≥3 条）。得 **867 篇**候选。
   初版词表漏掉了 `deep potential`、`operator inference`、`shallow recurrent decoder` 等写法，经人工抽查后补齐重跑。
2. **摘要级分诊**：29 个 agent，每个读 30 篇摘要，逐篇判定是否真属"AI × 物理科学"（剔除只是提了一嘴 physics 的 CV/NLP/机器人论文、剔除无学习成分的纯数值方法），并按 23 类主题打 significance / novelty / evidence 三项分。得 **501 篇**保留、363 篇剔除。
3. **漏检回捞**：12 个 agent 扫描被关键词筛掉的 **3,558** 条标题，找出可能的假阴性 75 篇；再对这 75 篇做摘要级分诊，追加 **53 篇**。
4. **最终入选 554 篇**（501 + 53）。

## 3. 精读与对抗式事实核查

- 对 significance ≥ 4 的 **65 篇**做全文精读：抓 arXiv 摘要页 + HTML 全文（无 HTML 版的注明只用摘要），提取方法、训练数据规模、物理约束、基线、关键数字。
- 每篇再交给一个**独立的对抗式核查 agent**，重新抓原文，逐条核对精读 agent 列出的每一个数字断言，并单独记录"论文自己吹过头、读者应打折扣"的地方。
- 结果：**4,345 条数字断言**经逐条核对——4,325 条获原文支持、9 条被判夸大、9 条与原文矛盾、2 条查无实据。65 篇的核查结论为 52 篇 CONFIRMED、13 篇 MOSTLY_CONFIRMED，无 PARTLY_WRONG 或 UNSUPPORTED。
- 正文里凡标 `[原文核查]` 的条目出自这 65 篇；`[摘要级]` 的只看过摘要；`[期刊扫描·未核查]` 的只确认了存在性与刊出日期。**三者证据强度不在一个量级。**

## 4. 非 arXiv 信源

arXiv 抓不到期刊正式发表与实验室发布，因此另跑一路 8 个方向的扫描（Nature 系 / Science 系 / APS-IOP 系 / 工业与国家实验室 / 社区文摘 / 热点子领域 / LLM-for-physics / 会议与竞赛），每条再经存在性与日期核查。得 **125 条**唯一条目，其中 **75 条**是纯期刊/博客渠道的净增量（arXiv 语料里没有对应件）。

## 5. 写作与三轮审稿

- 13 个主题 agent + 6 个跨领域趋势 agent 依据上述语料成稿。
- **三位审稿人**分别从完整性、"打假"、读者代表三个角度审稿，共提出 46 条意见（含漏收 Nature 正刊、重复计数、证据层级被抹平、把自己的打折标准只用在别人身上等）。
- 19 节全部按审稿意见修订（共采纳约 380 处修改），并为每条重点工作加挂成熟度与证据层级标签。
- 最后一轮终审校对做跨章一致性检查（重复计数、标签冲突、数字冲突、裸奔百分比、链接格式），再据此定稿。

## 6. 已知盲区

诚实列出，读者据此打折：

1. **检索索引滞后**不是问题（见 §1），但**尚未公告的论文**（09-03 14:00 ET 之后提交的）确实不在内——它们对所有人都还不可见。
2. **非英文渠道**基本没覆盖：中文期刊、日韩本土会议、俄语文献都不在检索范围。
3. **闭源工业成果**只能看到对方愿意发布的部分。本期的 DeepMind / Google / 微软 / OpenAI / Anthropic 条目多为博客与技术报告，无法做同级核查。
4. **期刊条目未做同级核查**：125 条非 arXiv 条目只核了存在性与日期，说法为原样转述，没有精读，也没有 factcheck。它们与 65 篇精读**不可并列读**。
5. **分诊由模型完成**，因而带系统性偏好：写得像 ML 论文的物理工作更容易被判高分，而"AI 只占一小节但结论重要"的实验物理论文可能被低估。significance 打分是摘要级判断，未经原文核查。
6. **主题切分会造出假空白**：同一条线索被拆到两章时，任何一章的"这个方向本期是空白"都可能只是切分的产物。本篇已就四处已知情形加了交叉引用，但不保证穷尽。
7. **单一窗口不构成趋势**：两周的样本量不足以支撑"某方向正在升温/降温"这类断言。本篇的趋势判断只在"本窗口内可观察到什么"这个意义上成立。
