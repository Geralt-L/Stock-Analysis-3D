# 港股通标的十年新低筛选（2026-08）

筛选港股通（南向）全部标的中，最近一个月（2026-07-08 ~ 2026-08-07）前复权价格创出十年新低的股票。

## 结果

见 [report.md](report.md)。摘要：

- 上市满十年且近一月创十年新低：**37 只**（严格新低 29 只，追平前低 8 只）
- 上市不足十年但创上市以来新低：80 只（其中上市满 5 年的 17 只）

## 方法

1. **成分股名单**：港交所披露易「港股通（南向 SH & SZ）持股纪录」全部证券（955 只，含仅可卖出证券）
   来源：`https://www3.hkexnews.hk/sdw/search/mutualmarket.aspx?t=hk`
2. **行情数据**：腾讯行情接口 `web.ifzq.gtimg.cn/appstock/app/hkfqkline/get`，日线前复权（qfq），
   单次上限 800 条，按结束日期向前翻页取满十年
3. **判定**：近一月盘中最低价（前复权）≤ 此前十年（2016-08-08 ~ 2026-07-07）盘中最低价
4. **验证**：抽样与雅虎财经 `adjclose` 交叉核对，收盘价口径判定一致

## 文件

| 文件 | 说明 |
|------|------|
| `fetch_all.py` | 拉取全部标的十年前复权日线并计算新低标记 |
| `report.py` | 由 `results.json` 生成 `report.md` / `hits.json` |
| `validate.py` | 用雅虎财经复权收盘价抽样交叉验证 |
| `ggt_list.json` | 港股通标的名单（代码 + 英文名） |
| `results.json` | 每只标的的原始计算结果 |
| `hits.json` | 命中名单（结构化） |
| `report.md` | 最终筛选报告 |

## 注意事项

- 前复权口径下，大额特别派息/分拆会使早年价格为负（如 00001 长和），此类个股天然难创新低，属口径固有特性
- 26 只标的近一月无成交（长期停牌，如恒大系）未纳入判定
- 上市不足 5 年的次新股「历史新低」多为破发，参考意义有限，报告中单独分层
